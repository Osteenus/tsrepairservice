## Остаётся проверить / улучшить

1. Первоначальный HTML не содержит основной отрисованной страницы; content и Head metadata зависят от JavaScript. Для надёжности начального HTML и social preview стоит отдельно рассмотреть Inertia SSR/prerender. В этом аудите архитектура рендеринга не менялась.
2. Фактическая индексация, Google-selected canonical, sitemap processing и rendered HTML в Search Console проверяются после публикации. Локальная проверка их не заменяет.
3. Lighthouse/PageSpeed и реальные Core Web Vitals не измерялись; оценка скорости и SEO score не выставлялись.
4. На Refrigerator остаются старые обещания same-day/certification в видимом контенте/общем trust strip. Нужна отдельная сверка с реальными условиями компании. Этот аудит ограничен техническими исправлениями.
5. /extra — доступная дополнительная страница вне основной навигации и sitemap. Нужно решить, должна ли она быть публичной/indexable; noindex автоматически не добавлялся.
6. Не все страницы услуг имеют Service/BreadcrumbList JSON-LD. Это дальнейшее улучшение, не препятствие базовой индексации.
7. Внешняя Google-карта, официальная индексация и работа поисковых роботов не подтверждались локальным тестом.
